## What This Project Does

This system automatically classifies field check-in images taken by RTV field workers into
9 operational categories: compost, goat-sheep-pen, guinea-pig-shelter, liquid-organic,
organic, pigsty, poultry-house, tippytap, and vsla.

The goal is to replace or augment manual compliance review with a fast, accurate, and
field-deployable classifier that integrates into RTV's existing WorkMate and data warehouse
ecosystem.

## Setup Instructions

### Step 1 — Install Python

Make sure you have Python 3.9 or later installed.
Check by running: `python --version`

### Step 2 — Place Your Data

Copy your 9 image folders into the `data/` directory so it looks like:
```
data/
  compost/       ← all compost images go here
  goat-sheep-pen/
  guinea-pig-shelter/
  liquid-organic/
  organic/
  pigsty/
  poultry-house/
  tippytap/
  vsla/
```

### Step 3 — Install Dependencies

Open your terminal in the project root folder and run:

```bash
pip install -r requirements.txt
```

### Step 4 — Run Task 1: Data Analysis

```bash
python src/dataset.py
```

This will:
- Count images per class and show the class distribution
- Print a summary of any quality issues found
- Show you the train/validation/test split sizes

### Step 5 — Run Task 2: Train the Model

```bash
python src/train.py
```

This will:
- Load and augment the dataset
- Train an EfficientNet-B0 model (pre-trained on ImageNet, fine-tuned on RTV data)
- Save the best model to `outputs/best_model.pth`
- Generate training curves plot

Then run evaluation:

```bash
python src/evaluate.py
```

This will:
- Load the saved best model
- Evaluate on the held-out test set
- Print per-class precision, recall, F1
- Save a confusion matrix image to `outputs/confusion_matrix.png`

### Step 6 — Run Task 3: Start the API

```bash
cd api
pip install -r requirements_api.txt
uvicorn main:app --reload --port 8000
```

Then test it by sending a request:

```bash
curl -X POST "http://localhost:8000/predict" \
  -H "accept: application/json" \
  -F "file=@/path/to/your/image.jpg"
```

Expected response:
```json
{
  "category": "poultry-house",
  "confidence": 0.84,
  "status": "success"
}
```

Interactive API documentation (auto-generated by FastAPI) available at:
`http://localhost:8000/docs`

### Step 7 — Run with Docker (Task 4, Optional)

```bash
# Build the container
docker build -t rtv-classifier .

# Run the container
docker run -p 8000:8000 rtv-classifier
```

## Key Design Decisions

- **EfficientNet-B0**: Chosen over ResNet50 because it achieves better accuracy at smaller
  model size — critical for future edge deployment on Android field devices.

- **Weighted sampling for class imbalance**: Some RTV categories have fewer images.
  Rather than discarding data (undersampling) or generating fake samples (SMOTE),
  we weight the loss and sampler so minority classes are learned equally.

- **Albumentations for augmentation**: Field photos have real-world variation —
  different lighting, angles, partial occlusion. Augmentation prepares the model
  for this without needing more labelled data.

- **FastAPI over Flask**: FastAPI is async, auto-documents via Swagger, validates
  types automatically, and is the production standard for ML serving in Python.

## Assumptions

1. Images are JPG or PNG format (standard field phone photos).
2. Each image belongs to exactly one category (single-label classification).
3. The `data/` folder structure uses the folder name as the class label.
4. A GPU is not required — the model trains on CPU in ~20–40 minutes for 20 epochs.
   If a GPU is available, training is automatically detected and used.
